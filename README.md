# Community-Connect---Civic-Issue-Reporter
Empowering communities to report, track, and resolve local civic issues together


basic web project to report local civic issues (potholes, garbage, streetlights etc) on a map.

live demo: https://sejalshukla2406-art.github.io/Community-Connect---Civic-Issue-Reporter/

* (what it does)
basically wanted to make a simple site where people can just mark problems in their area instead of complaining on helplines.

- you can click anywhere on the map to drop a pin or just use the gps button
- fill a small form (title, category like roads/water, and details
- shows all reports in a sidebar feed
- upvote button so people can upvote serious issues
- filter dropdown to check only specific issues
- a small chart showing which issue has the most reports
- saves data in localstorage so issues dont vanish when you refresh

* ( stuff used)
- HTML / CSS (used flexbox for layout, tried to keep it responsive)
- plain JS (no react or anything, just vanilla js for dom, events, localstorage)
- leaflet.js for the map
- chart.js for the circle chart
- deployed with github pages
